Within each folder there is a slurm* script which contains the main code being run. Various output files are also included.

## Benchmarking comparisons

UpsetPlot- compare transcripts between annotations

SQANTI3- sqanti analysis

Manual-comparison- find novel transcripts for manual comparison with IGV
